Big Data – Mental Health Data Platform

 Présentation:

Ce projet a été réalisé en équipe dans le cadre de la formation en Data Science.

L’objectif est de développer une plateforme permettant d’explorer et d’analyser des données relatives à la santé mentale des étudiants, afin d’identifier des tendances et des facteurs liés à leur bien-être psychologique.

 Objectif du projet:

Le projet vise à :

- analyser un jeu de données sur la santé mentale des étudiants ;
- effectuer le traitement et l’exploration des données ;
- extraire des informations et des tendances pertinentes ;
- présenter les résultats à travers une interface interactive.

Technologies utilisées:

- Python
- Pandas
- Streamlit
- Hadoop / HDFS
- Apache Spark
- Apache Hive
- HBase
- Docker

 Données:

Le projet utilise un jeu de données portant sur la santé mentale des étudiants.

Le fichier de données utilisé dans le projet est :

"MentalHealthSurvey.csv"

Dashboard:

Une interface interactive a été développée avec Streamlit afin de faciliter l’exploration et la visualisation des données.
